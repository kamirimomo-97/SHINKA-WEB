# SHINKA 0.60.1 — Rank ordinari

Distribuzione web approvata. Questo repository contiene esclusivamente i file dell’app pubblica, senza cronologia o documentazione del repository sorgente privato.

Apri https://kamirimomo-97.github.io/SHINKA-WEB/

I dati di allenamento vengono salvati nel browser del dispositivo. La versione è riportata in version.json. SHINKA PRIME rimane nel laboratorio, escluso dall’integrazione live di questa release.


La 0.60.1 separa il livello storico dal rank attivo e applica decadimento, retrocessioni e recupero con le regole ufficiali. Una copia locale del profilo precedente viene conservata prima della migrazione.
